ARROW OUT: free install (no Mac, no fees)

1) Put these files online for free (pick one):
   - Netlify: go to app.netlify.com/drop and drag this whole folder in.
   - GitHub Pages: make a free repo, upload these files, Settings > Pages > deploy from main branch.
   - Cloudflare Pages: free, upload the folder.
2) Open your link on the phone:
   - iPhone: Safari > Share button > Add to Home Screen.
   - Android: Chrome > menu > Install app (or Add to Home screen).
It then opens full screen like a normal app and works offline after the first load.

Updating: edit index.html, then change CACHE in sw.js (arrowout-v2) and upload again.
